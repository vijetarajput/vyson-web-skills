# Example reference file

Use files like this one for detailed material that the agent only needs sometimes, for example a long checklist, a vertical-specific playbook, or a table of values.

Guidelines:

- Keep each reference file focused on one topic. Smaller files use less of the agent's attention.
- Link to it directly from `SKILL.md`. Do not link from one reference file to another (keep links one level deep).
- Delete this file and its link if your skill does not need references.
