# Blind mapping (do not open before scoring)

> **If you are about to do the human review, stop here.** Fill in [`human-review-sheet.md`](human-review-sheet.md) first, using only the folders `blind-copies/A` and `blind-copies/B`. Open this file afterwards.

The assignment was made with a random choice (PowerShell `Get-Random`) after both runs had finished, and was stored outside the evaluator's folder until after the scored review.

| Label | Condition | Folder with the same files |
|---|---|---|
| A | WITHOUT the skill | `../outputs/without-skill/` |
| B | WITH the skill | `../outputs/with-skill/` |

`blind-copies/A` and `blind-copies/B` are exact copies of those output folders (HTML, CSS and JS only).
